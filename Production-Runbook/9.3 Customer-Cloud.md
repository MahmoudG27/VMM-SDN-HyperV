# 9.3 Customer cloud

> One VMM Cloud per customer. Values in `Customers/<Customer>/02 Cloud.md`.
> Microsoft's cloud wizard page couldn't be fetched when this was written. The page names below are from the console: confirm them on first use.

## 1. Create the cloud

MGMT01, **VMs and Services → Create Cloud** (View Script before Finish):

| Page | Value |
|---|---|
| General | Name `<Customer>-Cloud`, description |
| Resources | Host group `All Hosts\Provider-DC\Cluster1` |
| Logical Networks | ✔ `HNV-PA` only |
| Load Balancers | None |
| VIP Templates | None: this page serves self-service users, and VIPs are created by admins (9.2) |
| Port Classifications | `Medium bandwidth` |
| Storage | CSVs for this customer (classification if used) |
| Library | Read-only library shares, if any |
| Capacity | vCPU, memory, storage, VM count (from 9.1 + headroom) |
| Capability Profiles | Hyper-V |
| Replication Groups | None |

## 2. Cost Center and Tag: on the VMs

`New-SCCloud` has no Tag or Cost Center parameter. Both are **VM** properties (`Set-SCVirtualMachine -CostCenter -Tag`). Whether `Set-SCCloud` has them wasn't confirmed: **to be verified**. Write the values in the Cloud description too, and set them on every VM:

```powershell
# MGMT01 (VMM PowerShell) – after migration (9.4)
Get-SCVirtualMachine | Where-Object { $_.Cloud.Name -eq "<Customer>-Cloud" } |
    Set-SCVirtualMachine -CostCenter "<CostCenter>" -Tag "<Customer>"
```

## 3. A Cloud doesn't isolate VM networks

A Cloud does **not** stop a VM from being attached to another customer's VM network: the logical network is shared (`HNV-PA`). The controls are naming discipline and this check:

```powershell
# MGMT01 (VMM PowerShell) – must return nothing
Get-SCVirtualMachine | Where-Object { $_.Cloud } | ForEach-Object {
    $vm = $_; $customer = $vm.Cloud.Name -replace '-Cloud$', ''
    $vm.VirtualNetworkAdapters | Where-Object { $_.VMNetwork.Name -notlike "$customer-*" } |
        ForEach-Object { "{0} (cloud {1}) is on VM network {2}" -f $vm.Name, $vm.Cloud.Name, $_.VMNetwork.Name }
}
```
