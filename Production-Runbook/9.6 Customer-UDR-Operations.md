# 9.6 Customer UDR operations (Pattern B)

> Keeps customer firewalls in the path. VMM has no UDR support, so UDRs live only in NC, and **VMM can silently remove them (L28)**.
> Pattern definition and lab results: 9.0 §2 and §7.
> The script was tested against a **mock** Network Controller on 31 Oct 2026 (drift, repair, idempotency, single PUT, policy findings, VMM unreachable, cross-subnet next hop refused). The script as a whole hasn't run against a real NC yet: see §6. Its `-Force` calls worked in the lab.

## 1. Rules learned in the lab

| Rule | Lesson |
|---|---|
| `Import-Module NetworkController` before any `New-Object Microsoft.Windows.NetworkController.*` | L23 |
| Run on an NC node, or a machine with RSAT-NetworkController (MGMT01, 5.3) | – |
| Through `Invoke-Command`, pass the credential with `-ArgumentList` | L20 |
| Read passwords with `Read-Host -AsSecureString` + `New-Object PSCredential`. `Get-Credential` dialogs failed in the lab. Paste the `Read-Host` line **on its own** | Lab |
| Identify the virtual network by its **NC resource ID**, never by subnet prefix: customers overlap. The ID comes from VMM: `(Get-SCVMNetwork -Name <name>).ExternalId` equals the NC virtual network resource ID | Lab-verified |
| One PUT of the virtual network per run, only if a link changed, in a maintenance window. Re-test VIPs afterwards | L25 |
| A route table object surviving doesn't mean it's applied: check the subnet → route table link | L28 |
| Each route table lists **every other subnet** + `0.0.0.0/0`: with `0.0.0.0/0` only, traffic to another subnet of the VNet went directly via `.1`, not via the appliance | Lab-verified (T1) |
| **The next hop is always the firewall's IP in the SAME subnet as the route table.** A subnet without a firewall NIC gets a NIC, or stays an open question with no VMs on it. The script refuses anything else | Design rule (T2 inconclusive) |
| **Firewall admin access = its IP in your own subnet.** A multi-homed firewall VM answers on its own IP only from the NIC that owns that IP. Replies leaving another NIC are dropped by VFP | L29 |

## 2. `Apply-<Customer>-UDR.ps1`

Reconcile, idempotent. **Input:** the desired state at the top of the file. **Behaviour:**
1. Refuses to run while the desired state contains `<placeholders>`, or a next hop outside the route table's subnet.
2. Gets the NC resource ID from `(Get-SCVMNetwork -Name <name>).ExternalId` and caches it in `<Customer>.vnetid` next to the script. If VMM isn't reachable, it uses the cached ID and warns: the nightly backup stops the VMM service (8.4 §7), and the guard must keep working.
3. Refuses a VNet that lacks the expected subnets (wrong resource ID, or subnet not created).
4. Creates/updates the route tables.
5. Attaches them to the subnets, and PUTs the virtual network **once**, only if something changed.
6. Prints `No drift`, or the differences, then the final state.
7. Reports policy findings: VIP/NAT backend not the firewall (L26), Port ACL on a subnet or NIC (L22). These are **never** fixed automatically.

| Exit code | Meaning |
|---|---|
| 0 | OK: no drift, or drift fixed |
| 1 | Error (placeholders, next hop outside the subnet, NC or VMM unreachable with no cached ID, wrong VNet) |
| 2 | Drift found (`-CheckOnly`) |
| 3 | Policy finding |

**Template.** Copy to `Customers/<Customer>/Apply-<Customer>-UDR.ps1`, edit only the desired state. The complete worked example is `Customers/CustomerA-Dev/Apply-CustomerA-Dev-UDR.ps1`. The engine is the same in every customer script.

```powershell
[CmdletBinding()]
param(
    [string]       $ConnectionUri = "https://ncrest.contoso.local",
    [pscredential] $Credential,
    [string]       $VNetResourceId,
    [string]       $VmmServer = "VMM01.contoso.local",
    [switch]       $CheckOnly
)
$ErrorActionPreference = "Stop"

# ===== DESIRED STATE (values only: edit this block, never the engine) =====

$Customer      = "<Customer>"
$VMNetworkName = "<Customer>-Net"                  # the NC resource ID comes from this VM network's ExternalId
$FirewallIPs   = @("<external-firewall-ip>")       # allowed VIP/NAT backends (L26)

# Route table name -> routes. Every route is next hop type VirtualAppliance.
# List EVERY other subnet of the VNet + 0.0.0.0/0 (9.0 §7). NextHop = the firewall's IP in THIS subnet
$RouteTables = [ordered]@{
    "<Customer>-RT-<Tier>" = @(
        @{ Prefix = "<other-subnet>/24"; NextHop = "<firewall-ip-in-this-subnet>" }
        @{ Prefix = "0.0.0.0/0";         NextHop = "<firewall-ip-in-this-subnet>" }
    )
}

# EVERY subnet of the VNet. $null = no route table (the firewall's transit subnet, or a subnet with no firewall NIC and no VMs)
$SubnetMap = [ordered]@{
    "<tier-subnet>/24"    = "<Customer>-RT-<Tier>"
    "<transit-subnet>/24" = $null
}

# ===== ENGINE (same in every customer script: Production-Runbook\9.6) =====

function Get-RouteKey([string] $Prefix, [string] $NextHop) { ("{0}|virtualappliance|{1}" -f $Prefix, $NextHop).ToLowerInvariant() }

function Test-IpInPrefix([string] $Ip, [string] $Prefix) {
    $net, $len = $Prefix -split '/'
    $toInt = { param($a) $b = [System.Net.IPAddress]::Parse($a).GetAddressBytes(); [Array]::Reverse($b); [BitConverter]::ToUInt32($b, 0) }
    $mask  = if ([int]$len -eq 0) { [uint32]0 } else { [uint32]([uint64]4294967295 -band ([uint64]4294967295 -shl (32 - [int]$len))) }
    ((& $toInt $Ip) -band $mask) -eq ((& $toInt $net) -band $mask)
}

$placeholders = @($FirewallIPs) + @($RouteTables.Values | ForEach-Object { $_ } | ForEach-Object { $_.NextHop })
$open = @($placeholders | Where-Object { $_ -match '<' } | Sort-Object -Unique)
if ($open.Count -gt 0) { [Console]::Error.WriteLine("Desired state still has placeholders: $($open -join ', ')"); exit 1 }

# Design rule: the next hop is always the firewall's IP in the SAME subnet as the route table
$outside = @(foreach ($p in $SubnetMap.Keys) {
    if ($SubnetMap[$p]) {
        foreach ($r in $RouteTables[$SubnetMap[$p]]) { if (-not (Test-IpInPrefix $r.NextHop $p)) { "$($SubnetMap[$p]): $($r.NextHop) isn't in $p" } }
    }
})
if ($outside.Count -gt 0) { [Console]::Error.WriteLine("Next hop outside the subnet: $(($outside | Sort-Object -Unique) -join '; ')"); exit 1 }

try {
    Import-Module NetworkController       # before any New-Object Microsoft.Windows.NetworkController.* (L23)

    $nc = @{ ConnectionUri = $ConnectionUri }
    if ($Credential) { $nc.Credential = $Credential }

    # VMM VM network ExternalId = NC virtual network resource ID (lab-verified). The last good ID is cached,
    # so the guard keeps working while the VMM service is stopped by the nightly backup (8.4 §7)
    if (-not $VNetResourceId) {
        $idCache = Join-Path $PSScriptRoot "$Customer.vnetid"
        try {
            Import-Module VirtualMachineManager
            [void](Get-SCVMMServer -ComputerName $VmmServer)
            $vmn = Get-SCVMNetwork -Name $VMNetworkName
            if (-not $vmn -or -not $vmn.ExternalId) { throw "VM network $VMNetworkName not found, or it has no ExternalId" }
            $VNetResourceId = "$($vmn.ExternalId)"
            Set-Content -Path $idCache -Value $VNetResourceId
        } catch {
            if (-not (Test-Path $idCache)) { throw }
            $VNetResourceId = (Get-Content $idCache -TotalCount 1).Trim()
            Write-Warning "VMM not reachable ($($_.Exception.Message)): using the cached resource ID $VNetResourceId"
        }
    }

    $vnet     = Get-NetworkControllerVirtualNetwork @nc -ResourceId $VNetResourceId
    $prefixes = @($vnet.Properties.Subnets | ForEach-Object { $_.Properties.AddressPrefix })
    $missing  = @($SubnetMap.Keys | Where-Object { $_ -notin $prefixes })
    if ($missing.Count -gt 0) { throw "VNet $VNetResourceId has no subnet $($missing -join ', '): wrong resource ID, or subnet not created yet" }

    $drift  = New-Object System.Collections.ArrayList
    $tables = @{}
    Get-NetworkControllerRouteTable @nc | ForEach-Object { $tables[$_.ResourceId] = $_ }

    # 1. Route tables
    foreach ($name in $RouteTables.Keys) {
        $want = @($RouteTables[$name] | ForEach-Object { Get-RouteKey $_.Prefix $_.NextHop } | Sort-Object)
        $have = @()
        if ($tables.ContainsKey($name)) {
            $have = @($tables[$name].Properties.Routes | ForEach-Object {
                "{0}|{1}|{2}" -f $_.Properties.AddressPrefix, $_.Properties.NextHopType, $_.Properties.NextHopIpAddress
            } | ForEach-Object { $_.ToLowerInvariant() } | Sort-Object)
        }
        if (($want -join ';') -eq ($have -join ';')) { continue }

        [void]$drift.Add("Route table $name differs from the desired state")
        if ($CheckOnly) { continue }

        $props = New-Object Microsoft.Windows.NetworkController.RouteTableProperties
        foreach ($r in $RouteTables[$name]) {
            $route = New-Object Microsoft.Windows.NetworkController.Route
            $route.ResourceId = $r.Prefix -replace '[./]', '_'
            $route.Properties = New-Object Microsoft.Windows.NetworkController.RouteProperties
            $route.Properties.AddressPrefix    = $r.Prefix
            $route.Properties.NextHopType      = "VirtualAppliance"
            $route.Properties.NextHopIpAddress = $r.NextHop
            $props.Routes += $route
        }
        [void](New-NetworkControllerRouteTable @nc -ResourceId $name -Properties $props -Force)
        $tables[$name] = Get-NetworkControllerRouteTable @nc -ResourceId $name
    }

    # 2. Subnet -> route table links (L28: VMM subnet changes remove them)
    $putNeeded = $false
    foreach ($s in $vnet.Properties.Subnets) {
        $prefix = $s.Properties.AddressPrefix
        if (-not $SubnetMap.Contains($prefix)) { Write-Warning "Subnet $prefix isn't in the desired state: add it to `$SubnetMap"; continue }
        $wantRt = $SubnetMap[$prefix]
        $haveRt = $null
        if ($s.Properties.RouteTable -and $s.Properties.RouteTable.ResourceRef) { $haveRt = ($s.Properties.RouteTable.ResourceRef -split '/')[-1] }
        if ($wantRt -eq $haveRt) { continue }

        [void]$drift.Add("Subnet $prefix has route table '$haveRt', desired '$wantRt'")
        if ($CheckOnly) { continue }
        if ($wantRt) { $s.Properties.RouteTable = $tables[$wantRt] } else { $s.Properties.RouteTable = $null }
        $putNeeded = $true
    }

    # 3. One PUT of the virtual network, only if a link changed (L25: each PUT re-programs the hosts)
    if ($putNeeded) {
        [void](New-NetworkControllerVirtualNetwork @nc -ResourceId $vnet.ResourceId -Properties $vnet.Properties -Force)
        $deadline = (Get-Date).AddMinutes(5)
        do {
            Start-Sleep -Seconds 5
            $state = (Get-NetworkControllerVirtualNetwork @nc -ResourceId $VNetResourceId).Properties.ProvisioningState
        } until ($state -in "Succeeded", "Failed" -or (Get-Date) -gt $deadline)
        if ($state -ne "Succeeded") { throw "Virtual network $VNetResourceId ended in state '$state'" }
        Write-Warning "Virtual network updated: hosts were re-programmed. Re-test the VIPs now (L25)."
    }

    # 4. Final state
    if ($drift.Count -eq 0) {
        "No drift ($Customer)"
    } else {
        $drift | ForEach-Object { "DRIFT: $_" }
        if (-not $CheckOnly) { "Applied ($Customer)" }
    }
    $final = Get-NetworkControllerVirtualNetwork @nc -ResourceId $VNetResourceId
    $final.Properties.Subnets | ForEach-Object {
        $ref = if ($_.Properties.RouteTable) { ($_.Properties.RouteTable.ResourceRef -split '/')[-1] } else { "(none)" }
        [pscustomobject]@{ Subnet = $_.Properties.AddressPrefix; RouteTable = $ref }
    } | Sort-Object Subnet | Format-Table -AutoSize | Out-String | Write-Output

    # 5. Policy checks: reported, never fixed automatically
    $findings = New-Object System.Collections.ArrayList
    foreach ($s in $final.Properties.Subnets) {
        if ($s.Properties.AccessControlList -and $s.Properties.AccessControlList.ResourceRef) {
            [void]$findings.Add("Port ACL on subnet $($s.Properties.AddressPrefix) (L22): $($s.Properties.AccessControlList.ResourceRef)")
        }
    }
    $ipByRef = @{}
    foreach ($n in @(Get-NetworkControllerNetworkInterface @nc)) {
        foreach ($c in @($n.Properties.IpConfigurations)) {
            if (-not $c.Properties.Subnet -or $c.Properties.Subnet.ResourceRef -notlike "/virtualNetworks/$VNetResourceId/*") { continue }
            $ipByRef[("/networkInterfaces/{0}/ipConfigurations/{1}" -f $n.ResourceId, $c.ResourceId).ToLowerInvariant()] = $c.Properties.PrivateIPAddress
            if ($c.Properties.AccessControlList -and $c.Properties.AccessControlList.ResourceRef) {
                [void]$findings.Add("Port ACL on NIC $($c.Properties.PrivateIPAddress) (L22): $($c.Properties.AccessControlList.ResourceRef)")
            }
        }
    }
    foreach ($lb in @(Get-NetworkControllerLoadBalancer @nc)) {
        $refs = @()
        foreach ($pool in @($lb.Properties.BackendAddressPools)) { $refs += @($pool.Properties.BackendIPConfigurations | ForEach-Object { $_.ResourceRef }) }
        foreach ($rule in @($lb.Properties.InboundNatRules))     { if ($rule.Properties.BackendIPConfiguration) { $refs += $rule.Properties.BackendIPConfiguration.ResourceRef } }
        foreach ($ref in ($refs | Where-Object { $_ })) {
            $ip = $ipByRef[$ref.ToLowerInvariant()]
            if ($ip -and $ip -notin $FirewallIPs) { [void]$findings.Add("Load balancer $($lb.ResourceId) has backend $ip, not the firewall (L26)") }
        }
    }
    $findings | ForEach-Object { "FINDING: $_" }

    if ($CheckOnly -and $drift.Count -gt 0) { exit 2 }
    if ($findings.Count -gt 0) { exit 3 }
    exit 0
}
catch {
    [Console]::Error.WriteLine("ERROR: $_")
    exit 1
}
```

## 3. Guard

One scheduled task on **MGMT01**, every **5 minutes (placeholder)**. It runs every `Apply-*-UDR.ps1` in `C:\Scripts\UDR` in check mode, re-applies on drift, and writes events for monitoring.

```powershell
# MGMT01 (once, elevated) – folder, event source, guard script
New-Item -ItemType Directory -Path C:\Scripts\UDR -Force | Out-Null
New-EventLog -LogName Application -Source "SDN-UDR-Guard" -ErrorAction SilentlyContinue
@'
$dir = "C:\Scripts\UDR"
function Write-Guard([int] $Id, [string] $Type, [string] $Text) {
    Write-EventLog -LogName Application -Source "SDN-UDR-Guard" -EventId $Id -EntryType $Type -Message $Text
}
function Invoke-Apply([string] $Path, [string[]] $Extra) {
    $out = & powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Path @Extra 2>&1 | Out-String
    [pscustomobject]@{ Code = $LASTEXITCODE; Output = $out }
}
foreach ($s in Get-ChildItem "$dir\Apply-*-UDR.ps1") {
    $check = Invoke-Apply $s.FullName @("-CheckOnly")
    switch ($check.Code) {
        0 { }
        2 {
            $fix = Invoke-Apply $s.FullName @()
            if ($fix.Code -in 0, 3) { Write-Guard 1002 Warning "$($s.Name): UDR drift found and RE-APPLIED. Re-test the VIPs (L25) and find what changed (L28).`n$($check.Output)`n$($fix.Output)" }
            else                    { Write-Guard 1001 Error   "$($s.Name): UDR drift found, re-apply FAILED.`n$($fix.Output)" }
        }
        3 { Write-Guard 1003 Warning "$($s.Name): policy finding (L22/L26).`n$($check.Output)" }
        default { Write-Guard 1001 Error "$($s.Name): check failed (exit $($check.Code)).`n$($check.Output)" }
    }
}
'@ | Set-Content C:\Scripts\UDR\Invoke-UDRGuard.ps1
```

| Event ID | Type | Meaning | Action |
|---|---|---|---|
| 1001 | Error | Check or re-apply failed | Immediate: the firewall may be out of the path |
| 1002 | Warning | Drift re-applied | Re-test VIPs, find which VMM change caused it |
| 1003 | Warning | VIP backend not the firewall, or a Port ACL | Fix it in VMM, verify in NC |

- Between a VMM change and the next guard run (up to 5 min), **the firewall is out of the path**. The guard is a safety net, not the procedure: §4 is.
- Password rotation of `svc-sdn`: re-register the task.
- `svc-sdn` needs **write** access to `C:\Scripts\UDR` (ID cache) and **read** access in VMM to get `ExternalId`:

## 4. Change procedure

**Any VMM change to the subnets of a Pattern B VM network:**

| # | Step | Machine |
|---|---|---|
| 1 | Maintenance window agreed (L25) | – |
| 2 | Add the new subnet to the desired state first: `$SubnetMap` + every route table | Git repo, then `C:\Scripts\UDR` |
| 3 | Make the VMM change | VMM console |
| 4 | **Immediately** run `Apply-<Customer>-UDR.ps1` | MGMT01 |
| 5 | Run `-CheckOnly`: exit 0, `No drift` | MGMT01 |
| 6 | Re-test VIPs from outside HNV-PA (L25, L27) and one cross-subnet `tracert` | Test client |
| 7 | Record in `05 As-Built.md` | – |

The warning in the VM network description (9.2 §2) points the VMM operator here.
Port ACL changes on any customer: check NC afterwards (L22).

## 5. Checks

| Check | How | Expected |
|---|---|---|
| UDR state = desired state | `Apply-<Customer>-UDR.ps1 -CheckOnly` | `No drift` |
| No VIP/NAT with a non-firewall backend (L26) | Same run | No `FINDING` |
| No Port ACL on Pattern B subnets or NICs, **in NC** (L22) | Same run | No `FINDING` |
| Guard running | `Get-ScheduledTaskInfo "SDN - UDR Guard"` on MGMT01 | `LastTaskResult = 0` |
| No guard alerts | `Get-EventLog Application -Source SDN-UDR-Guard -Newest 20` on MGMT01 | No 1001 |
| Firewall admin access (L29) | From a VM in the firewall's subnet, to the firewall's IP **in that subnet** | Answers. Its IP in another subnet doesn't answer, and that's normal, not a fault |
| Monitoring / backup of the firewall (L29) | Target = the firewall's IP in the monitoring system's subnet | Configured |

## 6. Pilot checks (to be verified on the first real run)

| Item | Why |
|---|---|
| NC property names used by the script (`Properties.RouteTable.ResourceRef`, `AccessControlList`, `BackendAddressPools`, `InboundNatRules`) | Only tested against a mock. The Microsoft page shows lower-case `properties.subnets[0].properties.RouteTable` |
| VMM role `SDN-UDR-Read` can read `ExternalId` | Otherwise the guard uses only the cached ID, and fails with no cache |
| Outbound NAT (NAT connection) combined with the external firewall's own SNAT | The lab VNet used an L3 connection, not outbound NAT, so this path wasn't tested |
| Several SLB VIPs on the same public IP with different ports | The lab used one VIP per IP |
